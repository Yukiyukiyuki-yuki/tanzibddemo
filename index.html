关于这个工具 · 设计思路

这是针对谈资 BD 岗位场景设计的一个调研工具原型。

解决的真实问题：BD 拿到一个品牌合作意向时，需要快速搞清楚"这个品牌是谁、行业在发生什么、谈资能给什么"。靠人工要花半天到一天，这个工具目标是压到 2 分钟。

技术栈：支持 DeepSeek API 和 Anthropic Claude API 两种调用方式。前端是单个 HTML 文件，所有逻辑在 prompt 设计里。

差异化设计：核心不是"调用 AI 做调研"——这事谁都能做。关键是 system prompt 里内置了谈资资源矩阵（主号、Big 榜、看好戏、在场up、「在场」App、城市营销、政企客户对接能力）。AI 每次输出合作方向时必须从这个矩阵里选具体资源，给出的是"用 X 资源做 X 事"而不是泛泛建议。

下一步可以做的：接入实时联网搜索（Tavily/SerpAPI）、历史调研记录、导出 PPT 提案、资源矩阵管理（让 BD 团队可编辑）、批量调研。
